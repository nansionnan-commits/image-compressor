图瘦身 v8 — 便携版说明
======================

这是一个 Windows 单文件图片压缩工具, 不需要装 Python.

使用步骤
--------
1. 双击 "图瘦身.exe" 启动 (首次 Windows SmartScreen 拦就点 "更多信息 → 仍要运行")
2. 用 Windows 资源管理器把图片拖进窗口 (支持 jpg/png/bmp/webp/tif, 单张/多张/整个文件夹都行)
3. 选个预设 (推荐先试 ⚡推荐压缩 或 📦主图≤200KB)
4. 点 "▶ 开始压缩"
5. 压缩完去 "输出" 框指向的目录收成品 (默认与 exe 同目录下的 compressed\<预设名>\)

⚠ 原图绝对安全: 输出撞原图路径时自动加 _compressed 后缀, 永不覆盖. 重复运行会覆盖旧的压缩输出, 不碰原图.

完整使用文档: https://github.com/nansionnan-commits/image-compressor/releases/latest
